Key Learnings & Fixes Made
Fix #1
Label Masking
Broken masking caused stuck loss. Fixed by encoding the prompt-only portion first to get the exact token cutoff before applying -100 mask.
Fix #2
Caption Overfitting
Identical per-class captions caused severe overfitting. Solved with 10 dynamic templates per disease, giving 200+ unique combinations.
Fix #3
Windows venv Error
PowerShell permission errors resolved with --without-pip flag during venv creation.
