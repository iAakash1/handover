# Keras model evaluations

**What is here:** Custom CNN and the three transfer-learning models with per-class results and confusion matrices.

**Results:** CNN 98.51% (tomato test); MobileNetV2 90.90%, EfficientNetB3 93.59%, ConvNeXt 96.15% (held-out 20% validation).

**Finding:** ConvNeXt is the best Keras backbone.
