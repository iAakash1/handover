# MLX tomato and mango metrics

**What is here:** Precision and recall computed from the published confusion matrices in [https://github.com/iAakash1/experimentation/tree/refactor/professional-research-layout/research/mlx_pipeline](https://github.com/iAakash1/experimentation/tree/refactor/professional-research-layout/research/mlx_pipeline).

**Results:** Tomato: macro precision 0.937, recall 0.912. Mango: macro precision 0.920, recall 0.820.

**Finding:** Mango Die Back is the weak class (recall 0.04).
