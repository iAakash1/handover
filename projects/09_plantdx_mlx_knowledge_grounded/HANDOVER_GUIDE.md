# Handover guide: PlantDx MLX models, tomato and mango (project 09)

Two separately trained and evaluated models that share one code base, the `plantdx` package in `src/plantdx/`.
**They run on macOS with Apple Silicon only (Apple MLX);** they are not the CUDA models of projects 06, 07 and 10.
Detailed cards: [`models/qwen25vl_tomato_qlora`](models/qwen25vl_tomato_qlora/README.md),
[`models/qwen25vl_mango_qlora`](models/qwen25vl_mango_qlora/README.md); step by step:
[`docs/REPRODUCTION.md`](docs/REPRODUCTION.md).

## Shared method

- **What they do:** describe a leaf photo in one diagnostic caption that names the disease and its signs.
- **Captions:** compiled, not generated by a model: cited Disease Knowledge Base (`knowledge_base/dkb.json`) →
  ontology → controlled vocabulary → per-disease concept models → templates → 1,966 validated captions
  (`artifacts/corpus/`, sha256 `1225eb86…`). Each image gets one (question, answer) pair.
- **Base model and quantisation:** `mlx-community/Qwen2.5-VL-7B-Instruct-4bit` (4-bit MLX weights, downloaded from
  Hugging Face on first use, about 6 GB).
- **LoRA:** rank 16, alpha 32 (scale 2.0), dropout 0.05; mlx-vlm 0.6.4 applied it to q/k/v/o and gate/up/down of all
  28 language-model layers (196 modules, `checkpoints/<run>/adapter_config.json`); vision tower frozen;
  **40,370,176 trainable parameters**.
- **Training:** `mlx_vlm.lora` via `plantdx train`: LR 1e-4 (constant in the logs), micro-batch 1 × gradient
  accumulation 8, 1 epoch, images 448 × 448, max sequence 2,048, loss on answers only, gradient checkpointing,
  split seed 20260711. mlx-vlm 0.6.4 takes no training seed and uses no validation set during training.
- **Install:** `conda create -n vlm python=3.12 -y && conda activate vlm`, then from this folder
  `pip install -e ".[train]" -r requirements-mlx.txt` (mlx 0.31.2, mlx-vlm 0.6.4, mlx-lm 0.31.3, transformers
  5.12.1). Metrics run in a second environment: `./scripts/setup_eval_env.sh`.
- **Hardware:** trained on an Apple M4 Pro with 24 GB; training peak 7.2–7.4 GB, evaluation peak about 12 GB.
- **Check a clone (any OS):** `python scripts/verify_project.py`.

## Commands (from this folder, MLX environment)

```bash
python ../../setup/download_models.py 09_plantdx                                   # fetches both adapters (works from any folder)
plantdx infer --adapter checkpoints/qwen25vl_tomato_qlora --image leaf.JPG
plantdx infer --adapter checkpoints/qwen25vl_mango_qlora --image leaf.jpg \
              --instruction "Describe the visible condition of this mango leaf."
streamlit run streamlit_app.py                                                     # demo; pick the crop in the sidebar
plantdx normalize                                                                  # raw images -> datasets/<crop>/processed
plantdx prepare-training --config configs/train/qwen25vl_tomato.yaml              # regenerates the July split row for row
plantdx train --config configs/train/qwen25vl_tomato.yaml                         # mango: qwen25vl_mango.yaml --crop mango
plantdx evaluate --stage inference --adapter checkpoints/qwen25vl_tomato_qlora \
                 --dataset artifacts/training/qwen25vl_tomato_qlora/dataset --output-dir reports/new_eval_tomato
plantdx evaluate --stage analyze --output-dir reports/new_eval_tomato              # in the metrics environment
```

## Modify / extend

Each run is one YAML file in `configs/train/` (model, LoRA, optimiser, data). Disease knowledge is
`knowledge_base/dkb.json`; `plantdx ontology / vocabulary / concepts / generate` rebuild the captions from it with
recorded content hashes. The mango run shows how to add a crop: a train config, an instruction bank in
`assets/training/`, and the images under `<crop>/raw/`.

## Limitations and known issues

- Apple Silicon only; nothing here runs on CUDA. The package and CLI (without training or inference) run anywhere.
- Retraining is not bit-exact (mlx-vlm 0.6.4 has no seed), which is why the November scores differ from July.
- Weakest classes: tomato early blight, mango die back. `docs/KNOWN_ISSUES.md` lists the rest.
- The zero-shot benchmarks and caption experiments that came before this pipeline are in
  [`../../failed_experiments/11_mac_earlier_experiments/`](../../failed_experiments/11_mac_earlier_experiments/README.md).
