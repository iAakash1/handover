VALIDATION REPORT — Crop Disease Caption Dataset
=================================================
Generated: 2026-06-23
Source archive: caption.zip (16 usable images; macOS metadata files and

METHOD
------
Every image was opened and visually inspected directly before any caption
was written. Folder/filename labels (e.g. "Curl Virus", "lateblight",
"bacterial spot") were treated only as a starting hint, per the brief.
Where the image did not clearly support the labeled symptom, the caption
describes only what is actually visible rather than assuming the label.

GLOBAL CHECKS
-------------
1. Repetition check: see duplicate_similarity_report.txt. 80 captions
   compared pairwise (3,160 pairs); 0 pairs exceeded the 0.80 similarity
   threshold.
2. Phrase frequency check: see caption_statistics.txt. No content word
   or opening bigram dominates the dataset. The single most frequent
   opening token is the article "the" (18/80 = 22.5%), which the stats
   script flags automatically — this is expected for English prose and
   each instance is followed by a different noun/subject ("the veins...",
   "the margin...", "the contrast...", "the upper-right lobe...", etc.),
   so it isn't a templated-phrase problem in practice, just a property of
   the naive single-word metric. No banned boilerplate phrases ("the
   image shows", "displaying symptoms", "infected leaf", etc.) appear
   anywhere in the dataset — checked manually against the full caption
   list.
3. Symptom-consistency check: see per-image notes above. One genuine
   conflict area was found and documented (the two bell pepper images
   with generalized chlorosis vs. the two with discrete spotting) —
   resolved in favor of visual appearance, not the shared folder label.

LIMITATIONS
-----------
- Sample size is small (16 images) — this is a caption-quality pilot for
  the existing crop subset in caption.zip, not a full-dataset run.
- Disease identification is based on visual pattern-matching to common,
  well-documented presentations (consistent with general plant pathology
  references such as PlantVillage-style symptom descriptions for these
  same crop/disease classes); it is not a substitute for expert
  pathologist confirmation, which the brief itself flags as the next
  step.
